# Code of Conduct

POSTBote follows the [Rust Code of Conduct](https://www.rust-lang.org/policies/code-of-conduct).

In short: be friendly and patient, welcoming and respectful. Harassment, insults and personal attacks
are not tolerated, in issues, pull requests, discussions or anywhere else in the project's spaces.
Disagree about ideas, never about people.

## Reporting

If someone makes you or anyone else feel unsafe or unwelcome, please contact the maintainer privately
(see the maintainer's GitHub profile for contact details). Reports are handled confidentially. The
maintainer may edit or remove comments, commits, issues and other contributions that do not follow
this code of conduct, and may block people who repeatedly or seriously violate it.
